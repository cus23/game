# GOOD DAY｜3D 便利商店收銀模擬器

一款以台灣街角便利商店為主題的 3D 瀏覽器遊戲。玩家在 3D 店面中操作收銀台，將貨架上的商品拖曳至掃描區、管理購物明細、收款找零，並接待持續移動的顧客。

## 功能
- Three.js 即時 3D 店面：貨架、商品、收銀櫃檯、店內裝飾與人物。
- 3D 商品拖曳：將貨架商品拖至收銀台掃描區，加入購物明細。
- 顧客排隊、人物待機動作與結帳離場動畫。
- POS：商品明細、數量調整、會員折扣、現金收款、找零、信用卡與電子支付模擬、收據。
- 商品庫存、補貨、營收與交易日誌。
- localStorage 自動保存進度，支援桌面與手機觸控。

## 操作
1. 在 3D 場景中按住商品並拖到右側收銀台。
2. 商品進入掃描區後會加入購物明細。
3. 調整數量或登記會員，按「結帳收款」。
4. 選擇付款方式，現金需輸入付款金額並確認找零。
5. 完成交易後，顧客離開並由下一位顧客上前。
6. 庫存不足時到「商品庫存」頁補貨。

## 技術
- HTML、CSS、JavaScript ES Modules、Three.js 0.160。
- Three.js 由 jsDelivr CDN 載入，第一次開啟 3D 場景需要網路連線。
- 遊戲資料儲存在瀏覽器 localStorage。
- 信用卡與電子支付只作遊戲內流程模擬，不會連接銀行或產生真實扣款。

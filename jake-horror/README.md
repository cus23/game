# GOOD DAY｜便利商店 POS 模擬器

一款以台灣街角便利商店為主題的多頁面收銀台模擬遊戲。玩家扮演門市店長，從商品掃描、購物車管理到收款找零，完整操作一筆筆日常交易。

## 主要頁面

- **收銀作業 POS**：商品分類、條碼／名稱搜尋、商品加入、數量調整、會員折扣、顧客候位清單。
- **付款結帳**：現金收款與找零、信用卡模擬、電子支付模擬、交易收據。
- **商品管理**：商品主檔、條碼、分類、售價、庫存狀態與低庫存提醒。
- **進貨補貨**：選擇商品與進貨數量、計算進貨成本、即時更新庫存、進貨紀錄。
- **營運報表**：累積營收、交易筆數、平均客單價、每日營收圖表、本週目標與交易紀錄。

## 操作方式

1. 在「收銀作業」選擇商品卡片，或輸入商品條碼／名稱搜尋。
2. 在右側購物車調整數量、移除商品，或登記會員套用折扣。
3. 按「前往結帳」，選擇現金、信用卡或電子支付。
4. 現金付款可輸入實收金額，系統會計算找零。
5. 完成交易後查看模擬收據，並接待下一位顧客。
6. 庫存不足時，前往「進貨補貨」建立進貨單。

## 技術與資料

- HTML、CSS、原生 JavaScript，無需 API 金鑰或後端服務。
- 使用 localStorage 自動保存遊戲進度、庫存、交易與進貨紀錄。
- 響應式介面，支援手機與桌面瀏覽器。
- 信用卡與電子支付僅為遊戲內流程模擬，不會連接真實銀行或扣款。
